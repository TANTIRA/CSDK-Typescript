# Security Policy

## Supported versions

Security fixes go into the latest release. Upgrade to it before you report an issue, in case it is already fixed.

## Reporting a vulnerability

Do not report security vulnerabilities in public GitHub issues, discussions or pull requests.

Report them privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Include:

- the SDK version and runtime version you used;
- a description of the issue and its impact;
- steps to reproduce, or a minimal proof of concept;
- any suggested fix or mitigation.

## What to expect

- We aim to acknowledge your report within 5 business days.
- We will investigate, keep you informed, and agree on a disclosure date with you.
- Once a fix is released, we publish a GitHub security advisory. With your consent, we credit you for the report.

Please give us reasonable time to fix the issue before you disclose it publicly, and test only against data and accounts you own.

## Scope

This policy covers the code in this repository. Vulnerabilities in the Converge platform itself, or in third-party dependencies, can be reported the same way. We will route them to the right owner.
